Quickstart

Your first request in a minute

No sign-up and no key during the beta. Open a terminal and follow along.

    Base URL & format

    All requests go to one base URL over HTTPS. Responses are JSON, dates are YYYY-MM-DD, and quarters are written 2026-Q4.

    Base URL
    Formatapplication/json
    Versionv1 (in the path)

    List endpoints wrap results in data and describe the page in meta. Pass meta.next_cursor back as cursor to fetch the next page.

    Access & rate limits

    No key needed

    The API is open during the beta. Just send a request.

    Per IP address. Every response tells you where you stand in the X-RateLimit-* headers.

    Errors

    Errors use standard HTTP status codes and return a short JSON body you can show or log.

    StatusCodeWhen it happens
    400invalid_parameterA filter has the wrong format, e.g. quarter=Q4 instead of 2026-Q4.
    404not_foundNo project matches that id.
    429rate_limitedToo many requests. Wait for the number of seconds in Retry-After.
    500server_errorSomething broke on our side. Try again shortly.

    The project object

    Every project returned by /projects has this shape.

    Statuses

    These follow the growth tracker’s methodology, so API numbers and the published growth figures always agree.

    active

    Listed in the directory and verifiable.

    inactive

    Shut down, stopped operating or can no longer be verified. Kept so history stays complete.

    removed

    No longer on the latest infographic. removed_in says which quarter it dropped off.
